# Phone Commander

Двухпанельный файловый менеджер для macOS с доступом к iPhone по кабелю.

Сборка: `brew install libimobiledevice`, затем `./build.sh`. Приложение: `build/Phone Commander.app`.
Проверка на подключённом iPhone: `"build/Phone Commander.app/Contents/MacOS/PhoneCommander" --selftest`.

- Tab: другая панель. Enter: открыть. Backspace: вверх. Пробел на файле: выбрать следующий. Пробел на папке: посчитать её размер.
- F2 имя, F3 просмотр, F5 копия, F6 перенос, F7 папка, F8 удаление. На клавиатуре Mac с клавишей fn. Те же действия есть кнопками внизу.
- Меню содержит все команды с сочетаниями ⌘. Правая кнопка мыши открывает контекстное меню.
- Групповое переименование: ⌘⇧M или F2 при нескольких выбранных. Шаблон: [N] имя, [C] счётчик, [D] дата, [T] время.
- Выделение: + по маске, - снять по маске, * инвертировать.
- Фильтр по имени: ⌘F, Esc сбрасывает. Набор букв в списке переходит к файлу.
- С iPhone: копирование из DCIM с датами файлов, проверкой размера и пропуском уже скопированного.
- На iPhone: AirDrop в «Фото». Запись по кабелю видна только в этом приложении.
- Системные папки iPhone (DCIM, PhotoData и другие) защищены от записи и удаления.
